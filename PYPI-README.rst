=========================
Gamma-ray Targeted Search
=========================

The Gamma-ray Targeted Search (GTS) is a generalized, mission agnostic, version
of the Fermi-GBM Targeted Search that is built around the `Gamma-ray Data Tools <https://astro-gdt.readthedocs.io/en/latest/>`_.

Normal Installation
-------------------

If you don't plan to contribute code to the project, the recommended install method is installing from PyPI using:

.. code-block:: sh

   pip install gts

Contributing Code or Documentation
----------------------------------

If you plan to help with the development or documentation of astro-gdt, then please visit our github site at
https://github.com/USRA-STI/gdt-core.
